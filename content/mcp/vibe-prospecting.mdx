## Overview

Vibe Prospecting is a remote MCP server for B2B company and contact intelligence in prospecting workflows.

## Installation

```bash
claude mcp add --transport http vibe-prospecting https://vibeprospecting.explorium.ai/mcp
```

OAuth authentication is completed through the browser.

## Usage

After connecting the server, ask Claude to find B2B SaaS companies in New York with 50–200 employees, enrich the decision-makers, and export the list to CSV.
