## Overview

**Council of AI GSPC** is the remote MCP door at [https://councilof.ai/mcp](https://councilof.ai/mcp).
It reads the live 22-axis GSPC board, lists signed measurement cards, and verifies a card under the published Ed25519 rule. **Measurement, not certification** — empty cells stay empty; UNMEASURED is a first-class answer.

Seven tools are free. Four paid tools speak x402 (USDC on Base). Calling a paid tool without payment returns HTTP 402, which is a quote, not a sale.

## Key capabilities

| Tool | Cost | What it does |
| --- | --- | --- |
| `board_totals` | free | Live slot count vs measured count, never summed |
| `get_axis` | free | One axis row: n, interval, MEASURED or UNMEASURED |
| `verify_card` | free | Three-state verdict: VALID / INVALID / UNCHECKABLE |
| `list_cards` | free | Signed-card index vs store count, disagreement shown |
| `get_root` | free | Public Merkle root |
| `get_card` | free | Fetch one published card |
| Paid x402 tools | USDC on Base | `commission_card`, `art50_marking_evidence`, `rwa_evidence`, `receipts_batch` |

## Installation

### Claude Code (remote HTTP)

```bash
claude mcp add --transport http gspc https://councilof.ai/mcp
```

### Claude Desktop / any stdio client

```json
{
  "mcpServers": {
    "gspc": {
      "command": "npx",
      "args": ["-y", "csoai-gspc-mcp"]
    }
  }
}
```

The npm package `csoai-gspc-mcp@0.2.1` talks to the same live endpoints.

## Requirements

- Network access to `https://councilof.ai`.
- No API key for the free tools.
- A funded Base USDC wallet only if you call a paid tool.

## Security

- Verification is free and loginless. Paid tools are opt-in x402; a 402 body is not settlement.
- Do not treat a GSPC score, a VALID card, or a 402 receipt as certification or a compliance badge.
- Source of truth: [https://councilof.ai/signed/HOW-TO-VERIFY.md](https://councilof.ai/signed/HOW-TO-VERIFY.md).
